# 캠페인 현장 3D 설계

> **[결정]** (사용자, 2026-11-19)
> - 절차 생성 사건의 3D 현장은 뒤로 미루고, 캠페인의 각본 사건부터 **손으로 만든** 3D 공간을 만든다.
> - 지금의 프롤로그 「첫 문장」과 제1장 「이미 찍힌 문장」을 없애고, **수능 AI 부정행위 사건**으로 바꾼다.
> - 사건의 출발: 「이번 수능 철저한 감독 이행 끝에 시험 전 AI부정행위 전부 검거.」라는 기사가 이미 났다. 그런데 한 커뮤니티가, 작년 수능 등급이 5·6·5·4·5였던 수험생이 한 해 만에 전 과목 1등급을 받은 것을 의심한다.
> - 수법의 뼈대: 천장에 숨긴 AI, 개조한 컴퓨터용 사인펜, 미끼 뿔테 안경.
> - 그 수험생은 전 과목 1등급이지만 **수학 한 문제를 틀렸다.** 마지막 증거는 그 오답과 AI의 오답을 맞대는 것이다.
> - 추리 과정은 현장 조사, 인물 대화, 구매 기록, 통신·금융 기록 같은 여러 조사 방식으로 보여 준다.
> - 인물은 종이 인형이 아니라 **실제 3D 모델**로 만들고, 캠페인의 3D 공간은 모두 **사실적으로** 만든다. 소품·인물 같은 3D 에셋은 TripoAI와 Blender MCP로 만들고, 레벨은 Blender에서 블록아웃으로 짠 뒤 사실적인 공간으로 디자인한다.
> - TripoAI는 유료 구독이라 생성물을 상업적으로 쓸 수 있다. 웹 Tripo의 순서는 그림 생성 → 스마트 메시(토폴로지 조정) → 텍스처 → (인물은 리깅 → 애니메이션) → Blender. 3D 화면은 three.js로 그린다. 3D 에셋은 당분간 로컬에 둔다. 색연필 표시와 수첩 그림체는 만드는 쪽이 디자인으로 판단한다.
>
> 그 밖의 내용은 모두 **[제안]**입니다. 큰 방향은 [방향 전환](direction-proposal.md)에 있습니다.
>
> **[구현]**이라고 적은 곳은 `feature/campaign-3d` 작업 폴더에 실제로 만들어 시험한 내용입니다(2026-11-19). 3D 에셋은 로컬에만 있습니다. 구현된 것은 15절의 1~3단계(현장 엔진과 목원고 12시험실, 수첩, 증거판)입니다. 모두 포크의 `feature/campaign-3d` 가지에 커밋돼 있고, 팀 저장소에는 아직 올리지 않았습니다. 현장은 `/site.html?site=mokwon_room12`에서 따로 열리며, 본 게임과는 아직 이어져 있지 않습니다. 본 게임에는 옛 프롤로그와 제1장이 그대로 있습니다([캠페인 시나리오](../design/campaign.md)).
>
> 이 문서의 번호(`P1`, `C1`, `I1`…) 가운데 12시험실에 쓰는 `P1`, `P2`, `P4`, `P5`, `P7`, `P8`, `C1`~`C11`, `C17`, `C29`, `I1`, `I2`, `I4`~`I7`, `I12`, `I13`, `N1`, `N2`만 코드(`public/js/data/sites/mokwon.js`)에 있고, 나머지는 설계용입니다.

## 1. 현장의 문법

| 단위 | 뜻 |
|---|---|
| 장소 | 사건 하나의 무대. 방 여러 개. 국가 지도에서 이동해 들어온다 |
| 방 | 문으로 이어지는 공간. 방 사이 이동에는 시간이 들지 않는다 |
| 조사점 | 다가가면 붉은 색연필 동그라미가 뜨는 곳. 종류는 문서 / 물건 / 흔적 / 인물 |
| 잠금 | 열리려면 조건이 필요한 조사점이나 문: 증거, 대화, 시각, 또는 도장 |

**단서의 꼴**

| 꼴 | 어디에 쌓이나 | 얻는 법 |
|---|---|---|
| 사실 | 수첩 | 조사점을 살피거나 인물이 말한다 |
| 증거 | 증거판 카드 | 사실 가운데 증거가 되는 것 |
| 진술 | 증거판 카드 | 대화 기록에서 플레이어가 한 구절에 밑줄을 긋는다 |
| 추론 쪽지 | 증거판 카드 | 카드 둘 이상을 올바르게 이으면 생긴다. 대화에서 내밀 수 있고, 추리의 빈칸에 들어간다 |
| 상식 | 증거판 카드 | 세상이 '원래 안다'고 믿는 문장. 출처 칸이 비어 있다. 도장이 찍힌 뒤에 생긴다 |

수첩의 사실도 증거판으로 꺼내 카드로 쓸 수 있습니다.

**규칙**
- 살펴보기 5~15분, 대화 한 번 10분, 3D 열람 5분이 게임 시계에서 흐릅니다. 걷기와 방 이동에는 들지 않습니다. 수첩·증거판을 펼치면 시계가 멈춥니다.
  - **[구현]** 12시험실에서는 조사점마다 2~10분, 질문 하나에 4분, 천장 속 열람 5분으로 두었습니다. 시간은 **처음 살펴볼 때만** 듭니다. 다시 보는 것, 가진 물건을 꺼내 보는 것(I)은 공짜입니다. 드는 시간은 살펴보기 전에 조사점 옆에 "5분"으로 미리 보입니다. 수치는 12시험실 한 곳을 한 시간 반 안에 끝낼 수 있게 잡은 것이고, 장소가 늘면 다시 맞춥니다(정할 것 ⑮).
- **두 경로**: 추리에 꼭 필요한 단서는 두 길로 얻을 수 있게 둡니다. 되도록 사람(대화)과 물건(조사점)으로 나눕니다. LLM 대화가 엇나가도 진행이 막히지 않습니다. 단서마다의 두 길은 10절에 있습니다.
- 살펴본 조사점에는 색연필 체크가 남고, 수첩의 방 지도에 "아직 보지 않은 곳"이 점으로 남습니다.

## 2. 현장의 생동감

| 장치 | 내용 |
|---|---|
| 인물의 하루 | NPC가 게임 시각에 따라 움직인다. 배수정은 금요일 15~17시에만 목원고 교무실에 오고, 오기철은 6~15시에 시설관리실에 있고, 차승민은 일요일 14~17시에만 작업실에 온다. 시각을 골라 찾아가는 것도 조사가 된다 |
| 반응하는 공간 | 무엇을 집어 들면 근처 NPC가 한마디 한다. 시설관리실에서 사다리를 들면 오기철이 "제가 해 드릴까요?" 한다. 짧은 고정 대사로, LLM을 부르지 않는다. **[구현]** 12시험실의 배수정은 다섯 번 끼어든다: 석고 가루("시험 날엔 칠판을 안 써요. 분필 가루일 리가 없는데."), 깜빡이는 구멍, 사다리, 텍스, 장치. 말풍선이 뜨고 고개를 끄덕인다 |
| 빛이 시계다 **[구현]** | 12시험실에는 금요일 16시 50분에 들어선다. 해가 서쪽 창으로 낮게 들어 책상 그림자가 길게 눕는다. 조사에 시간을 쓰면 17시 24분에 해가 지고, 18시쯤에는 형광등 빛만 남는다. 시계를 보지 않아도 흐른 시간이 방에 보인다. 시간을 쓴 직후 빛이 몇 초에 걸쳐 바뀐다. 토요일 새벽 5시의 시한은 어둠 속에서 온다 |
| 빌려 온 사다리 **[구현]** | 깜빡이는 구멍을 찾으면 배수정이 "사다리가 있어야겠네요" 하고 시설관리실에서 접이식 사다리를 빌려 와 뒷문 옆에 둔다. 사다리 발의 격자무늬 고무는 바닥의 자국(C2)과 같은 무늬이고, 세우면 네 발이 그 자국에 그대로 들어맞는다. 그날 밤의 사다리가 바로 이것이라는 것을 손으로 알게 된다. **[제안]** 이때 시설관리실에 오기철이 있었다면 그는 누가 12시험실에서 사다리를 찾는지 알게 된다(정할 것 ⑭) |
| 견줄 것 **[구현]** | 단서 옆에 평범한 것을 하나 둔다. 23번 책상에는 지우개 가루뿐이고("다른 책상도 다 이렇다"), 뒷벽 좌석 배치도의 24번은 다른 줄과 나란하다. 무엇이 이상한지는 견주어야 보인다 |
| 소리 풍경 | 장소마다 고유한 소리: 옥탑방의 바람과 먼 버스, 목동 학원가의 형광등 웅웅거림과 셔틀버스, 빈 시험실의 벽시계 초침과 환풍기, 세운상가의 납땜 소리와 낡은 라디오. **[구현]** 12시험실은 소리 파일 없이 만들어 낸 낮은 방 소리와 형광등 안정기의 웅웅거림까지. 초침과 환풍기는 아직 없다 |
| 기다림 | 메모리 카드를 신고하면 경찰이 가져가고, 로그는 하루 뒤 윤태경의 전화로 온다. 그동안 다른 곳을 조사한다 |
| 시계의 압박 | 오기철은 토요일 새벽 5시에 장치를 회수하고, 차승민은 월요일 아침 9시에 출국한다. 둘 다 행정실 게시판과 작업실 메일에 미리 보인다(11절) |
| 첫 진입 | 장소에 처음 들어서면 화면 아래로 한두 줄의 현장 스케치가 흐른다("시험이 끝난 교실. 책상마다 수험번호 스티커가 아직 붙어 있다.") |

도장의 법칙을 보여 주는 장치(출처를 물으면 기억이 흔들리는 연출, 도장이 만든 기록의 붉은 번짐)는 이 사건에서는 플레이어가 직접 도장을 찍었을 때만 나옵니다. 다른 도장 주인과 맞서는 장에서 본격적으로 씁니다.

## 3. 3D 시각 연출

**[결정]** 공간은 사실적으로, 인물은 실제 3D 모델로 만든다. 아래의 세부는 [제안]입니다.

- **사실적인 공간**: 실제 한국의 교실, 학원, 아파트 경비실, 세운상가의 치수와 재질을 참고한다. 물리 기반 재질, Blender에서 미리 구운 조명, 환경광을 쓰고, 후처리는 톤 매핑과 옅은 주변 폐색 정도로 줄인다. 학교·학원·업체의 이름과 로고는 허구의 것을 쓴다.

| 장소 | 재질과 색 | 빛 |
|---|---|---|
| 옥탑방 | 낡은 장판, 합판 책상, 벽의 종이와 압정 | 책상 스탠드, 창밖 간판의 번짐 |
| 목동 아파트·학원가 | 베이지 타일, 스테인리스 우편함, 학원 간판의 원색 | 형광등, 이른 아침의 흐린 빛 |
| 목원고 | 짙은 초록 칠판, 연두 벽, 왁스 칠한 바닥, 구멍 뚫린 흰 텍스 천장 | 형광등, 오후의 긴 창빛과 떠다니는 먼지 |
| 세운상가 | 녹슨 초록 난간, 부품 상자의 빨강·노랑, 납땜 자국이 있는 작업대 | 백열등, 납땜 연기 |

- **인물은 3D 모델**: 등장인물마다 전신 모델을 만들고 뼈대를 넣는다. 동작은 서 있기, 말하기, 돌아보기와 인물별 몸짓 한두 개. 대사는 글이므로 입 모양 맞추기는 하지 않는다. 마음이 열릴수록 자세가 풀리고, 적대적이면 팔짱을 끼거나 몸을 돌린다(숫자 대신 몸짓). 허구의 인물이므로 실존 인물을 닮지 않게 한다.
- **조사점 표시**: 다가가면 붉은 색연필 동그라미. 살펴본 곳에는 체크. 사실적인 화면 위에 기자가 수첩에 긋는 표시를 한 겹 얹는 것이다. 아무것도 없는 곳은 표시하지 않는다(헛된 클릭을 줄인다).
- **집어 들기**: 물건이 화면 앞으로 떠오른다. 돌리고 뒤집고 확대한다. 결정적 디테일(펜 뒤 끝의 바늘구멍, 연습지의 광택 줄, 점검표의 날짜)을 찾으면 그 부분에 동그라미가 그려지고 증거가 된다.
- **겹쳐 보기**: 집어 든 물건 둘을 겹친다. 안경의 왼쪽 알 너머로 펜을 보면 라벨의 검은 네모에 글자가 뜨고, 오른쪽 알로는 아무것도 보이지 않는다.
- **비스듬한 빛**: 종이 물건을 열람할 때 손전등을 기울이면 눌린 자국과 광택이 드러난다.
- **카메라 화면**: 휴대폰을 들면 화면 속 화면이 생기고, 그 안에서만 눈에 보이지 않는 빛이 보랏빛으로 깜빡인다.
- **증거를 얻는 순간**: 화면 구석의 수첩이 펄럭이며 한 줄이 손글씨로 적힌다. 증거는 카드가 증거판 쪽으로 날아간다.
- **이동**: 방 사이는 문을 지나 끊김 없이. 장소 사이는 국가 지도로 나가 이동선이 그어지고 "목원고, 금요일 오후 3시" 같은 도착 카드가 뜬다.
- **조작**: WASD + 마우스 시점, 클릭 이동, 시야 70°, 머리 흔들림 거의 없음. 화면에는 가운데 점, 왼쪽 위의 장소·시각, 오른쪽 가장자리의 "지금의 물음" 한 줄만 둔다.

### 현장 엔진에서 정한 세부 [구현]

15절 1단계를 만들면서 정한 것입니다. 코드는 `public/js/site/`, 내용은 `public/js/data/sites/mokwon.js`에 있습니다.

**조작**

| 입력 | 하는 일 |
|---|---|
| W A S D (Shift: 빠르게) | 걷기 |
| 마우스 끌기 | 둘러보기. L을 누르면 마우스를 화면에 가둬 끌지 않고 본다 |
| 바닥 누르기 | 그 자리까지 가구를 피해 걸어간다 |
| 붉은 동그라미 누르기, 또는 E | 살펴본다. 멀면 먼저 걸어간다 |
| F / G | 휴대폰 카메라 / 개조된 펜을 든다 |
| I | 가진 물건을 3D로 꺼내 본다 |
| Tab | 수첩 (시계가 멈춘다) |
| B | 증거판 (시계가 멈춘다) |
| H / Esc | 수첩의 '조작' 쪽 / 닫기, 물러나기, 사다리에서 내려오기 |

**색연필 표시** (정할 것 ⑩의 답)

- 색은 교정용 붉은 색연필 하나(#C8321F). 사실적인 화면 위에 이 한 색만 얹습니다.
- 조사점에 다가가면 동그라미가 **한 획으로 그려집니다**. 손으로 그은 것처럼 조금 찌그러지고, 끝이 시작점을 살짝 지나칩니다. 획에는 색연필의 결(작은 빈틈)이 있습니다.
- 살펴본 곳에는 동그라미 대신 체크가 남습니다. 조건이 맞지 않은 조사점은 아예 보이지 않습니다.
- 3D 열람에서 디테일을 찾으면 같은 동그라미가 그 부분에 그려집니다.
- 증거를 얻으면 화면 오른쪽 위에 살짝 기운 수첩 쪽지가 뜹니다. 번호에는 붉은 동그라미가 쳐져 있고, 제목 아래에 "수첩에 적었다"가 붙습니다.

**수첩의 그림체**: 줄 쳐진 미색 종이에 붉은 세로줄 하나, 명조 글씨, 붉은 색연필과 검은 잉크 두 가지 색만 씁니다. 자막, 조사점 안내, 인물의 말풍선도 같은 종이 조각입니다. 3D 화면은 사진처럼, 그 위의 글과 표시는 모두 '기자가 수첩에 적은 것'처럼 보이게 나눕니다. 수첩과 증거판의 세부는 4절과 5절에 있습니다.

**도구**

- 휴대폰 카메라(F): 화면 한쪽에 휴대폰 화면이 뜹니다. 깜빡이는 구멍을 화면 한가운데에 **1초 남짓 붙들고 있어야** 찾은 것이 됩니다. 스쳐 지나가면 보랏빛이 언뜻 보일 뿐입니다.
- 개조된 펜(G): 왼쪽 알 너머로 본 펜이 뜨고, 네모에 `E`가 떠 있다가 그 텍스를 향하면 숫자로 바뀝니다. 휴대폰보다 겨누는 범위가 넓습니다.
- 가진 도구와 손에 든 것(사다리)은 화면 왼쪽 아래 띠에 보이고, 사다리를 들고 있는 동안에만 세울 자리가 표시됩니다.

**3D 열람**

- 끌어서 돌리고 휠로 다가갑니다. 디테일은 물건 안의 이름 붙은 점(`detail_*`)이고, 그 점이 보이는 쪽으로 돌리면 동그라미가 뜹니다. 눌러서 살펴봅니다. 뒤 끝의 바늘구멍은 펜을 돌려야 보입니다.
- 디테일에는 순서를 걸 수 있습니다. 천장 속에서는 '묶여 있는 것'을 먼저 알아봐야 타이, 마이크, 작은 화면, 메모리 카드가 열립니다. 점검표 스티커는 처음부터 볼 수 있습니다.
- 천장 속은 어둡고, 손전등이 마우스를 따라갑니다. **빛이 닿은 곳의 디테일만 드러나고**, 한 번 본 곳은 남습니다. 시점은 사다리 위에서 들여다보는 각도로 묶여 있습니다.
- 겹쳐 보기: 펜을 열람하는 동안 '뿔테 안경 · 왼쪽 알 너머로'나 '오른쪽 알 너머로'를 고르면 안경알이 마우스를 따라다닙니다. 왼쪽 알을 라벨의 네모 위에 잠깐 올려 두면 `E`가 뜨고, 오른쪽 알로는 아무것도 뜨지 않습니다. 둘 다 해 봐야 차이를 압니다.

**대화**

- 묻는 말은 자유롭게 씁니다. 증거를 두 장까지 내밀 수 있습니다.
- 답은 문장 단위로 나오고, **문장을 누르면 밑줄**이 그어져 수첩에 적힙니다. 그 문장이 인물이 아는 사실에 해당하면 진술 증거가 됩니다(C17 옮겨진 자리, C29 봉인).
- 인물이 말할 수 있는 사실은 규칙이 정합니다(늘 말함 / 특정 낱말을 물음 / 특정 증거를 내밂 / 신뢰도 / 특정 증거를 이미 가짐). 아직 열리지 않은 사실은 LLM에게 **보내지도 않습니다**. LLM의 답이 형식에 맞지 않거나 연결이 끊기면 규칙이 고른 고정 대사로 답합니다.
- 인물 모델은 서 있기(`idle`)와 끄덕이기(`agree`) 두 동작을 씁니다. 말하기 전용 동작은 Tripo의 기본 동작 목록에 없어 아직 없습니다.

**12시험실에 더한 단서**

- C10 전원 기록: 기판의 작은 화면에 가동 시간 `36:14:09`가 올라가고 있습니다. 금요일 17시 54분 기준으로 거꾸로 세면 목요일 05:40입니다. (화면은 그림 한 장이라 실제로는 올라가지 않습니다. 게임 시각에 맞춰 바뀌게 할지는 미정입니다.)
- C9 점검표: "소방시설 점검표" 스티커에 9월 정기 10:20 '김', 10월 정기 10:05 '김', 시험 전날 21:40 '오'. **앞의 두 줄은 낮이고 서명이 다릅니다.** 밤 9시 40분의 '오'만 튑니다. 시한을 넘기면 재점검 05:00 '오' 줄이 하나 더 생깁니다.
- C29 봉인 진술: 배수정 "전날 저녁 6시에 시험실을 봉인했어요. 그 뒤로 들어올 수 있는 건 당직하고 시설 쪽뿐이에요." 사다리 자국이나 깨진 텍스를 내밀면 나옵니다. 용의자의 범위를 좁히는 진술입니다(10절의 쓰임은 제안).
- 방송 스피커: "카메라로는 소리를 들을 수 없다. 그런데 도현은 듣기도 다 맞혔다." 천장 속 마이크의 복선입니다.
- 창: "전파는 이 창을 넘지 못했다. 그날은 차단기가 돌고 있었다." 추리 ③을 되새깁니다.

### 에셋과 레벨 제작

**[결정]** 3D 에셋은 TripoAI와 Blender MCP로 만들고, 레벨은 Blender에서 블록아웃을 먼저 짠 뒤 사실적으로 디자인한다. 아래의 순서와 수치는 [제안]입니다.

**레벨**

| 단계 | 하는 일 | 끝난 모습 |
|---|---|---|
| 1. 블록아웃 | Blender에서 1단위를 1m로 두고 방의 크기, 문, 창, 큰 가구를 상자로 짠다. 조사점·출발점·인물 자리·충돌 면을 빈 오브젝트로 놓고 이름을 붙인다(`spot_desk24_top`, `spawn_room12`, `npc_oh_facility`, `col_*`) | 회색 상자로 된 방 |
| 2. 걸어 보기 | 블록아웃을 glb로 내보내 게임에서 걸어 본다 | 동선, 시야, 조사점까지의 거리, 천장을 올려다보는 각도가 맞다 |
| 3. 사실화 | 벽·바닥·천장을 실제 재질로 바꾸고 가구와 소품을 넣는다. 빈 오브젝트의 이름과 자리는 그대로 둔다 | 사실적인 방 |
| 4. 굽고 줄이기 | 조명을 굽고, 메시와 텍스처를 줄여 glb로 내보낸다 | 게임에 넣는 파일 |

게임은 조사점과 인물의 자리를 glb 안의 이름에서 읽습니다. 그래서 블록아웃에서 사실화로 바뀌어도 사건 데이터를 고치지 않습니다(14절).

**소품과 인물**

- TripoAI로 글이나 참고 그림에서 모델을 만들고, Blender MCP로 불러와 실제 치수, 원점, 면 수, 재질을 다듬는다.
- **단서가 되는 디테일은 생성에 맡기지 않는다.** 펜 뒤 끝의 바늘구멍, 라벨의 검은 네모, 왼쪽 알의 반사색, 점검표의 날짜와 서명, 책상 밑 테이프 자국은 Blender에서 직접 만들거나 텍스처에 그린다.
- 3D 열람용 물건(개조 펜, 뿔테, 천장 장치, 연습지)은 가까이 보므로 정밀하게, 배경 소품은 가볍게 만든다.
- 인물은 생성 → 정리 → 뼈대 → 동작 순서로 만든다. 수첩의 초상은 같은 모델을 렌더해 쓴다.

**웹 예산** (재 보고 고친다): 장소 하나의 내려받기 30MB 이하, 화면의 삼각형 30만 개 이하, 텍스처는 열람용 2K와 그 밖 1K, 메시 압축과 압축 텍스처를 쓴다.

## 4. 수첩 (Tab)

기자 수첩 모양. 왼쪽 탭으로 넘긴다.

| 탭 | 내용 |
|---|---|
| 물음 | **지금 풀어야 할 물음** 목록. 추리마다 하나("24번 자리 위에는 무엇이 있나")와, 그 물음에 쓸 만한 카드가 몇 장 모였는지(●●○). 막막할 때 가장 먼저 보는 곳 |
| 사실 | 사건별 사실. '확인함 / 전해 들음 / 거짓으로 확인'을 색연필 표시로 구분 |
| 인물 | 초상, 역할, 한 말(밑줄 친 구절), 아직 묻지 않은 것의 힌트("오기철에게 '새벽 5시 38분'을 물어보지 않았다") |
| 장소 | 방 지도. 살펴본 곳 체크, 보지 않은 곳 점, NPC가 있는 시각 |
| 법칙 | 배운 도장의 법칙. 이 사건에서는 플레이어가 도장을 찍었을 때 ④ "찍은 자만 기억한다"를 배운다 |

### 수첩에서 정한 세부 [구현]

15절 2단계를 만들면서 정한 것입니다. 화면은 `public/js/site/notebook.js`, 쪽마다 무엇을 적을지는 `public/js/site/reason.js`가 정합니다. 스타일은 `public/css/site-paper.css`입니다.

- **모양**: 위쪽에 스프링이 달린 기자 수첩. 왼쪽에 색이 다른 견출지 여섯 장(물음·사실·인물·장소·법칙·조작)이 붙어 있습니다. 탭을 누르거나 ←/→, A/D, 1~6으로 넘기면 종이가 위로 넘어갑니다. 수첩을 펴고 있는 동안 시계는 멈춥니다. B를 누르면 수첩을 덮고 곧장 증거판으로 갑니다.
- **글씨**: 기자가 적은 것(사실, 인물의 말, 메모)은 손글씨(나눔손글씨 펜), 인쇄된 것(쪽 머리, 시각, 인물의 역할)은 고딕과 명조로 나눕니다.
- **새로 적힌 줄**: 지난번에 수첩을 덮은 뒤에 생긴 줄은 붉은 점이 붙고, 왼쪽에서 오른쪽으로 써 내려가듯 나타납니다. 그 쪽을 한 번 펴 보면 점이 사라집니다. 새 줄이 있는 탭의 견출지와, 현장 화면 아래 띠의 수첩 단추에도 붉은 점이 붙습니다. 프롤로그에서 이어받은 것은 처음부터 본 것으로 칩니다.
- **물음**: 지금의 물음 하나를 크게, 그 아래에 물음에 쓸 카드가 몇 장 모였는지(●●○)를 적습니다. 증거판에서 풀 물음에는 "증거판에서 푼다" 표시가 붙습니다. 열린 실마리, 시한까지 남은 시간, 빈칸 추리의 상태, 지나온 물음(줄을 그어 지움)이 그 아래에 이어집니다.
- **곰곰이 따져 본다**: 물음 쪽의 단추. 누르면 게임 속 **10분**이 흐르고 그 물음의 실마리가 하나 열립니다. 실마리가 다 열렸으면 단추가 사라집니다. 막혔을 때의 값은 시간입니다.
- **사실**: 확인함(✓), 전해 들음(❝), 거짓으로 확인(✕ 줄 그음), 추론(∴) 네 가지 표시를 붉은 색연필로 긋습니다. 조사점에서 본 것, 밑줄 친 말, 증거, 추론 쪽지가 얻은 순서대로 적힙니다.
- **카드로 꺼내기**: 증거 번호가 없던 사실 가운데 일부는 '카드로 꺼낸다'를 눌러 증거판에 올릴 수 있습니다(1절의 "수첩의 사실도 증거판으로 꺼내 카드로 쓸 수 있습니다"). 12시험실에서는 좌석 배치도(N1)와 방송 스피커(N2)입니다.
- **인물**: 테이프로 붙인 사진, 역할, 있는 곳, 기분(신뢰도를 말로 옮긴 한 줄), 알게 된 것, 밑줄 친 말, **아직 묻지 않은 것**. 사진은 3D 모델을 게임이 시작할 때 한 번 찍어 둔 것입니다. 만나지 못한 인물은 실루엣이고, 이름을 모르는 인물은 `'오'`처럼 아는 만큼만 적습니다(점검표를 본 뒤에 나타납니다).
- **장소**: 손으로 그린 평면도. 벽과 가구는 조금 떨리는 선이고, 살펴본 곳에는 ✓와 다닌 순서 번호(①②…), 아직 보지 않은 곳에는 점이 찍힙니다. 조건이 맞지 않아 보이지 않는 조사점은 지도에도 없습니다. 천장의 조사점은 점선 고리, 인물은 이름표, 내가 선 자리와 보는 방향은 화살표입니다. 지도 아래에 다닌 순서를 시각과 함께 적습니다.
- **법칙**: 12시험실에서는 도장을 찍을 일이 없어 "찍기 전에는 세 번 읽어라" 한 줄과 빈 칸만 있습니다.
- **조작**: 예전의 조작 안내(H)를 수첩의 마지막 쪽으로 옮겼습니다.

## 5. 증거판 (B)

옥탑방 벽에 실제로 있는 판(현장에서는 덮개로 연다). **빨간 실이 아니라 교정 부호**로 잇는다. 이 세계에서 도장은 교열하는 사람의 물건이기 때문이다.

**카드**: 증거(사진·문서), 진술(밑줄 구절), 인물, 추론 쪽지. 카드는 판 위에 자유롭게 놓는다.

**잇기**: 카드 둘을 고르고 관계를 고른다.

| 관계 | 교정 부호 | 예 |
|---|---|---|
| 맞지 않는다 (모순) | 붉은 ✕ 선 | 커뮤니티 "스마트 안경을 썼다" ↔ 감독관 "내가 검사했다, 플라스틱뿐이었다" |
| 같다 (일치) | 이중선 | 점검표의 21시 40분 ↔ 출입 기록의 21시 10분~22시 35분 |
| 앞뒤 (시간) | 화살표 | 9월 모의고사 5등급 → 수능 가채점 1등급 |
| 원문 (출처) | 고리 | 기관 보도자료 → 일간 세한 기사 |

- 맞는 연결이면 **추론 쪽지**가 생긴다. 틀리면 "이어지지 않는다"와 짧은 이유만 보이고 벌점은 없다. 같은 쌍을 세 번 틀리면 수첩의 '물음'에 힌트가 하나 더 열린다.
- **시간 띠**: 판 아래쪽의 시간 축. 시각이 있는 카드를 끌어 놓으면 저절로 자리를 찾는다. 시험 시간표가 기본으로 깔려 있어, 출입·전원·로그 기록이 어느 교시에 겹치는지 보인다.
- **판본 비교**: 같은 내용의 문장 카드 여럿을 겹쳐 놓으면 낱말 차이가 강조된다. 보도자료와 기사를 겹치면 기사가 지운 구절이 드러난다.
- **추리**: 객관식 대신 **빈칸 문장**에 카드를 끼운다. 빈칸에 맞는 추론 쪽지나 증거를 넣는다. 틀리면 왜 틀렸는지 알려 주고 게임 속 30분이 흐른다.
- **도장 자리**: 판 한쪽에 도장 자리가 있다. 기사 문장 카드를 올려 찍는다(12절).

### 증거판에서 정한 세부 [구현]

15절 3단계를 만들면서 정한 것입니다. 화면은 `public/js/site/board.js`, 판정은 모두 `public/js/site/reason.js`(순수 함수)가 합니다. LLM은 쓰지 않습니다.

**판의 짜임**

- 코르크 판, 그 아래 왼쪽에 시간 띠, 오른쪽에 원고지(빈칸 추리). 판 오른쪽 아래 구석에 도장 자리. 위쪽 띠에는 지금의 물음과 시각이 보입니다. 판을 펴고 있는 동안 시계는 멈춥니다(추리가 틀렸을 때만 흐릅니다).
- 판은 1600 너비의 가상 화면으로 그리고 창 크기에 맞춰 줄이거나 늘립니다.
- 현장에서는 B, 또는 화면 아래 띠의 증거판 단추로 엽니다. 새 카드가 생기면 그 단추에 붉은 점이 붙습니다.

**카드**

| 종류 | 모양 | 예 |
|---|---|---|
| 사진 | 붉은 압정으로 꽂은 즉석 사진. 아래 흰 여백에 손글씨 제목 | 현장에서 얻은 C1~C10, 가진 물건 P7·P8 |
| 문서 | 클립으로 집은 인쇄물. 귀가 접혀 있다 | 보도자료 P2, 기사 P1, 커뮤니티 글 P4 |
| 진술 | 수첩에서 찢어 낸 줄 종이. 밑줄 친 말이 손글씨로 적혀 있다 | P5, C17, C29 |
| 추론 쪽지 | 노란 메모지. 붉은 손글씨 제목 | I1, I4, I5… |

- **사진은 그 자리에서 찍힌다**: 증거를 얻는 순간의 3D 화면을 잘라 카드의 사진으로 씁니다. 셔터 소리와 함께 화면이 한 번 하얗게 번쩍이고, 쪽지가 화면 아래 증거판 단추로 날아갑니다. 3D 열람에서 얻은 것은 누른 디테일을 가운데에 두고 찍습니다. 가진 물건(안경, 펜)과 인물 사진은 시작할 때 모델을 따로 세워 놓고 찍습니다. 그림 파일은 따로 없고, 찍은 사진은 진행과 함께 브라우저에 저장됩니다.
- 카드는 끌어서 자유롭게 놓습니다. 놓은 자리는 저장됩니다. 새 카드는 빈자리를 찾아 놓이고, 추론 쪽지는 이은 두 카드 근처에 붙습니다.
- **프롤로그에서 이어받은 판**: 12시험실은 제1장의 첫 현장이므로, 프롤로그의 카드 여덟 장(P2, P1, P4, P5, P7, P8, I1, I4)이 이미 판에 붙어 있고 ✕ 선 둘이 그어져 있습니다. 추리 ①과 ③은 풀고 온 것이고(배수정이 문을 열어 준 까닭), ② 기사의 틈(I2)은 **아직 짚지 않은 채**로 둡니다. 판을 처음 여는 플레이어가 이미 그어진 선을 보고 잇는 법을 알게 하려는 것입니다.

**잇기**

- 카드 아래쪽의 연필 손잡이를 끌어 다른 카드에 놓거나, 카드를 하나씩 눌러 둘을 고릅니다. 그러면 관계 넷(✕ 맞지 않는다 / ═ 같다 / → 앞뒤 / ○ 원문)을 고르는 쪽지가 뜹니다. 1~4로도 고릅니다.
- 선은 붉은 색연필로 한 획씩 그려집니다. ✕는 선 가운데에 가위표, 같다는 이중선, 앞뒤는 **이른 쪽에서 늦은 쪽으로** 화살표, 원문은 끝에 고리가 달린 삽입 부호입니다.
- 맞으면 선이 남고 추론 쪽지가 태어납니다. 틀리면 연필 선이 잠깐 그어졌다가 지워지고, 이유를 적은 쪽지가 두 카드 아래에 뜹니다. 벌점도 시간도 들지 않습니다.
- 틀린 이유는 세 가지로 나눕니다. ① 이어지지 않는 쌍인데 이유를 따로 적어 둔 것(`misses`: "둘 다 바닥의 자국이지만 무늬가 다르다…"). ② 쌍은 맞는데 관계가 틀린 것("둘은 이어진다. 그런데 이 부호가 아니다."). ③ 그 밖("이어지지 않는다.").
- 같은 쌍을 세 번 틀리면 지금 물음의 실마리가 하나 열립니다.
- I5(석고 가루 ═ 사다리 자국)를 이으면 **판이 저절로 덮이고 카메라가 천장으로 올라갑니다.** 추리가 현장의 시선을 바꾸는 순간을 판 안에서 끝내지 않으려는 것입니다.

**판본 비교**

- 두 문서를 '원문'으로 이으면 두 장이 나란히 펴지고, 한쪽에만 있는 낱말에 형광펜이 칠해집니다(낱말 단위 비교).
- 여기서 **가장 무거운 차이 하나를 직접 짚어야** 쪽지(I2)가 됩니다. 꾸밈말을 짚으면 "덧붙인 말보다 사라진 말을 본다"가 돌아옵니다. 보도자료의 "시험 중 부정행위 여부는…"을 짚으면 그 구절에 붉은 동그라미가 쳐지고 I2가 생깁니다.

**시간 띠**

- 수요일 16시부터 토요일 7시까지. 시험 시간표(입실, 1~4교시)가 기본으로 깔려 있고, 지금 시각은 붉은 세로줄, 시한(토요일 5시 재점검)은 점선입니다.
- 시각이 있는 카드를 띠에 끌어 놓으면 제자리에 깃발로 꽂힙니다. 깃발을 누르면 뺍니다.
- C29(봉인 진술)를 올리면 수요일 18시부터 목요일 8시 10분까지 **'봉인' 띠**가 그어집니다. 그 안에 C9(21:40)나 C10(05:40)이 들어가면 깃발에 붉은 동그라미가 쳐지고, 처음 한 번 "문은 잠겨 있었다. 그 안에서 무언가가 올라가고, 켜졌다."가 뜹니다. 잇기 전에 눈으로 먼저 알아채게 하는 장치입니다.

**빈칸 추리 ④ 그날 밤**

- 원고지에 문장이 적혀 있고 빈칸 넷(어디 / 누가 / 언제 올렸나 / 언제 켰나)이 비어 있습니다. 천장 텍스를 연 뒤에 나타납니다.
- 카드를 빈칸에 끌어 놓습니다. 채운 칸에는 카드의 제목만 보이고, **맞았는지는 '맞춰 본다'를 눌러야** 압니다. 다 채워야 누를 수 있습니다.
- 틀리면 게임 속 30분이 흐르고, 틀린 칸마다 이유가 붙습니다("그것은 켠 시각이다", "서명 한 글자만으로는 좁혀지지 않는다. 봉인과 이어야 한다"). 맞은 칸은 그대로 남습니다. 세 번 틀리면 실마리가 하나 열립니다.
- 다 맞으면 빈칸이 활자로 바뀌어 한 문장이 됩니다. "두뇌는 24번 자리 위 천장에 있었다. 봉인된 방에 시설 쪽의 '오'가 들어와 시험 전날 밤 9시 40분에 그것을 올리고, 시험 날 새벽 5시 40분에 켰다."
- '누가' 칸은 카드가 아니라 **추론 쪽지(I12)**만 받습니다. 점검표나 봉인 진술을 따로 넣으면 틀립니다. 둘을 이어야 사람이 좁혀진다는 것을 추리의 규칙으로 삼았습니다.
- 시한을 넘겨 장치를 놓쳤으면 문장이 "…올렸다. 켠 시각은 아직 모른다."로 바뀌고 빈칸은 셋입니다.
- 이 문장은 설계의 추리 ④에서 '누가'를 이름 대신 "시설 쪽의 '오'"까지만 맞히게 줄인 것입니다. 이름(오기철)은 행정실의 출입 기록(C13)을 봐야 나옵니다.

**도장 자리**: 자리만 있습니다. 카드를 올리면 "찍을 수 있는 것은 문장뿐이다. 아직 찍을 문장이 없다."는 쪽지가 뜹니다. 찍는 일은 12절과 함께 만듭니다.

**소리**: 종이 넘기는 소리, 압정, 연필 긋는 소리, 지우는 소리, 셔터 같은 효과음을 파일 없이 합성합니다(`sfx.js`).

## 6. 대화

- 3D 공간 안에서 화면 아래 3분의 1에 덮개가 열린다. 인물은 그대로 공간에 서 있고, 카메라가 상반신이 보이는 거리로 다가간다.
- 자유 질문(LLM). 옆에 작은 카드 트레이: 카드를 끌어 놓으면 **내밀기**(두 장까지).
- 대화 기록의 아무 구절이나 드래그해 **밑줄** → 진술 카드. 그 인물이 실제로 아는 사실에 해당하는 구절이면 사실로도 기록된다.
- 대화를 끝내면 수첩의 인물 쪽에 "아직 묻지 않은 것" 힌트가 갱신된다.

## 7. 조사 방식

**공통 규칙**

1. **결과는 모두 카드다.** 어떤 화면에서 찾든 결과는 증거판의 카드가 되고, 같은 교정 부호로 잇고, 같은 빈칸 추리에 쓰인다.
2. **방식마다 '아하'가 하나다.** 각 화면에는 플레이어가 직접 알아채야 하는 패턴이 꼭 하나 있다. 읽기만 하면 끝나는 화면은 만들지 않는다.
3. **짧게.** 한 번에 2~5분. 같은 방식을 연달아 두 번 넘게 쓰지 않도록 사건을 짠다.
4. **판정은 규칙 엔진이 한다.** 자료는 손으로 쓰고, 패턴을 맞게 찾았는지는 규칙으로 판정한다. LLM은 대화에만 쓴다.

| 방식 | 화면 | 하는 일 | 이 사건의 '아하' |
|---|---|---|---|
| 현장 | 3D 1인칭 | 뒤지고, 집어 들고, 겹쳐 보고, 비스듬히 비춘다 | 왼쪽 알 너머로 본 펜에만 글자가 뜬다 / 책상 위 가루와 바닥의 사다리 자국 |
| 대화 | 3D + 대화 덮개 | 묻고, 내밀고, 밑줄을 긋는다 | 감독관: "펜을 거꾸로 들고 줄마다 긁으며 읽었다" |
| 장부 | 표 (정렬과 필터) | 조건을 조합해 행을 거른다 | 사인펜은 30자루인데 무광 뿔테와 소형 기판은 4개씩: 고객은 넷 |
| 시간 띠 (출입·통신) | 시간 축 위의 기록 | 시험 시간표와 겹쳐 본다 | 장치가 켜진 05:40, 학교에 들어온 사람은 05:38의 한 명뿐 |
| 시간 띠 (금융) | 돈 흐름 그래프 | 계좌 마디를 펼쳐 따라간다 | 학부모 넷 → 명문설계 → 한결전자 → 차승민 |
| 공개 정보 | 게임 속 웹 화면 (검색창, 커뮤니티, 학원 블로그, 기관 누리집, 지난 페이지 보관본) | 다른 단서에서 얻은 낱말로 검색한다 | 기사는 보도자료의 "시험 중 부정행위 여부는 확인할 예정"을 지웠다 / 삭제된 광고 "합격 보장, 장비 일체 제공" |
| 답안 대조 (이 사건 전용) | 문항별 답 겹쳐 보기 | 수험생별 답을 비교한다 | 서로 다른 시험장의 네 명이 수학 14번에서 똑같이 ③을 골랐다. 전국에서 ③을 고른 사람은 2%다 |

## 9. 장소별 공간과 배치

의혹 → 미끼 → 두뇌는 어디에. 잇기, 시간 띠, 판본 비교, 겹쳐 보기, 빈칸 추리를 처음 배운다.

## 11. 기록을 얻는 길과 도장

기자는 남의 기록을 마음대로 볼 수 없습니다. 이 제약을 숨기지 않고 **얻는 과정을 플레이로** 만듭니다.

| 기록 | 정당한 길 | 빠르지만 값을 치르는 길 |
|---|---|---|
| 시험실 출입 (프롤로그의 끝) | 배수정에게 추리 ①과 ③의 카드를 보여 주면, 금요일 수업이 끝난 뒤 그녀와 함께 들어간다 | 도장: 「이 기자는 이 수사의 경찰 자문위원이다」 |
| 학교 출입 기록과 수령 대장 | 배수정이 함께 있으면 행정실장이 보여 준다 | 정할 것 ④ |
| 메모리 카드 | 사진을 찍고 신고한다. 경찰이 가져가고, 하루 뒤 윤태경이 로그를 보여 준다 | 직접 뽑는다. 바로 보지만, 대면에서 "기자가 손댄 증거"라는 반박을 받아 답안 대조가 꼭 필요해지고 신뢰가 떨어진다 |
| 작업실 | 오기철의 자백, 또는 이웃 상인을 설득해 차승민이 없는 시각에 들어간다 | 정할 것 ④ |
| 돈의 흐름 | 작업실의 통장 사본, 또는 윤태경과 정보를 맞바꾼다 | — |
| 녹화 영상 (선택) | 윤태경 | — |

**접근 도장의 값**: 찍으면 시험실 문이 바로 열립니다. 그러나 모두가 "그 기자는 경찰 자문위원"이라고 알게 되므로 차승민도 압니다. 그는 그날 밤 작업실의 로그 사본을 지우고 출국을 하루 앞당깁니다. 장치를 놓치면 마지막 증거는 답안 대조뿐입니다. 이것이 플레이어가 도장의 값을 처음 겪는 자리입니다.

**대면**: 천장에서 기기가 나와도 도현은 "누가 날 모함하려고 단 거다, 난 내 실력으로 풀었다"고 버팁니다. 플레이어는 추리 ⑥의 카드를 하나씩 내밉니다. 공개 문제지 14번의 점선, 로그 속 뭉개진 스캔과 ③, 도현의 가채점 ③, 그리고 서로 모르는 다른 시험장의 세 명도 같은 ③을 골랐다는 것. 킬러 문항의 여백이 모두 비어 있다는 것도 함께 내밉니다. 도현이 무너집니다.

**그 뒤 [제안, 정할 것 ①]**: 국가시험관리원은 「전부 검거」를 지키려 합니다. 다시 조사하면 스스로 발표를 뒤집게 되기 때문입니다. 차승민은 월요일 아침에 떠납니다.

| 길 | 결과 | 값 |
|---|---|---|
| 폭로 기사 | 추리 ④⑤⑥이 모두 풀렸으면 월요일 아침 전에 수사가 움직여 차승민이 공항에서 붙잡힌다. 하나라도 비면 기사는 '의혹'에 그치고 차승민은 떠난다 | 시간 |

## 13. 표현의 선

- 실제 제품명은 쓰지 않습니다. 장치는 "작은 기판", "보조배터리", "빛 신호 장치" 같은 일반 명사로 부릅니다.
- 배터리 용량, 통신 방식의 이름, 탐지를 피하는 방법은 넣지 않습니다. 장치는 **무엇을 했는가**와 **어떤 흔적을 남겼는가**만 보여 줍니다. 따라 만들 수 있는 설명서가 되지 않게 합니다.
- "적외선은 눈에 안 보이고 카메라에는 보인다"처럼 누구나 아는 사실은 퍼즐로 써도 됩니다.
- 수능의 실제 규정(사인펜 지급, 입실 검색, 문제지 반출)은 참고하되, 시범 운영한 전파 차단기와 시험실 녹화는 게임 속 설정입니다.
- 화면의 계좌번호와 전화번호는 일부를 가린 형식으로 씁니다.

| `evidence` | 카드의 내용. 종류(`kind`), 제목, 본문, 시각, 판본 비교용 원문, 사진을 쓰지 않는 카드 표시(`noPhoto`) |
| `links` | 추론 쪽지를 만드는 연결. `from`(카드 둘), `rel`(contra / same / time / source), `alt`(다른 길), `compare`(판본 비교에서 짚을 구절), `close`(잇고 나면 판을 덮는다) |
| `misses` | 이어지지 않는 쌍 가운데 이유를 따로 적어 둔 것 |
| `deductions` | 빈칸 추리. `parts`(글과 `{ slot }`), `variants`(조건에 따라 바뀌는 문장), `slots`(`accept`: 카드와 문장에 들어갈 말, `near`: 아깝게 틀린 카드와 이유, `miss`), `wrongMinutes`, `effect` |
| `timeline` | 시간 띠. 범위, 기본 칸(`blocks`), 카드를 올리면 그어지는 띠(`bands`), 표시(`marks`) |
| `people` | 수첩의 인물 쪽. 조건에 따라 나타나는 인물과 줄(`when`) |
| `laws` / `map` | 수첩의 법칙 쪽 / 지도의 벽 이름표 |
| 물음의 `cards` / `hints` / `board` | 물음에 쓸 카드(●●○), 실마리, 증거판에서 푸는 물음인지 |
| 조사점의 `note` / `card` | 수첩의 사실 쪽에 적힐 줄 / 사진을 붙일 카드, 또는 꺼낼 수 있는 카드 |

glb 안의 이름 규칙: 방에는 `spot_*`(조사점), `spawn_*`(출발점), `npc_*`(인물 자리), `view_*`(정해진 시점), `col_*`(충돌 상자), `fx_*`(효과 자리). 열람용 물건에는 `detail_*`(디테일), `view_center`(돌리는 중심), 재질 이름 `*lens_film` / `*lens`(안경알). 상태에 따라 보이고 숨는 물건(`ladder_folded`, `ladder_open`, `tile24`)은 이름으로 켜고 끕니다.

아래는 처음의 제안입니다. 각본 사건(`scenes.js`)에 `site`를 더한다. 엔진은 장의 내용을 모르고 이 항목만 읽는다.

```js
site: {
  model: "sites/mokwon.glb",                  // Blender에서 만든 공간. 자리는 glb 안의 이름 붙은 빈 오브젝트에서 읽는다
  rooms: [{ id: "room12", label: "12시험실", spawn: "spawn_room12" }],
  spots: [{ id: "desk24_top", node: "spot_desk24_top", room: "room12", kind: "trace", label: "24번 책상",
            gives: { evidence: "C1" }, minutes: 5,
            lock: null /* { evidence: ["I4"] } | { talked: "bae" } | { hour: [15, 17] } | { before: "D+2 05:00" } */ }],
  npcs: [{ source: "oh", model: "chars/oh.glb", schedule: [{ from: 6, at: "npc_oh_facility" }, { from: 15, at: null }] }],
}
```

장에 `links.js`를 더해 추론 쪽지를 정의하고, `deductions.js`는 빈칸(`slots`)과 각 빈칸이 받는 카드로 바꾼다. (**[구현]** 12시험실에서는 따로 파일을 두지 않고 현장 정의 안에 `links`와 `deductions`로 넣었습니다.)

```js
I8: { from: ["C9", "C13"], rel: "same", title: "그날 밤의 손", text: "점검표의 21시 40분은 오기철이 학교에 있던 시간 안에 있다.",
      alt: [{ from: ["C10", "C13"], rel: "time" }] }
```
