# 방향 전환: 지도에서 현장으로, 추리 어드벤처

> **[결정]**은 사용자가 2026-11-19까지 정한 것이고, 나머지는 **[제안]**입니다. 팀이 정한 항목만 [게임 기획](../game-design.md)과 `design/` 문서로 옮깁니다. 지금 구현된 게임은 [게임 기획](../game-design.md)에 있습니다. 아직 아무것도 구현하지 않았습니다.

## 바꾸는 까닭

지금 게임은 기자 경영 시뮬레이션이 핵심 루프를 차지합니다. 목표가 불분명하고(A-8), 압박이 없고, 빈 종이에 기사를 쓰는 일이 막막하고, 도장을 쓸 이유가 약합니다(A-7). 이 게임에만 있는 것은 **문장 하나가 상식이 되는 도장**, **출처 없는 상식을 찾는 추리**, **도장이 일곱 개라는 설정**입니다. 이것을 핵심 루프로 올립니다.

## 정한 것 [결정]

| 항목 | 결정 |
|---|---|
| 경영 | 경영 시뮬레이션의 볼륨(수익, 구독, 등급, 인력, 지국, 투자)을 없앤다 |
| 지도 | 세계지도에서 나라를 누르면 그 나라의 지도로 들어간다. 세계지도에서는 조사·인터뷰를 할 수 없다 |
| 진행 순서 | 세계 → 국가 → 사건 선택(개요만 보임) → 사건이 난 지역으로 이동 → 3D 공간을 1인칭으로 돌아다니며 NPC와 대화하고 단서를 모아 추리한다 |
| 현장 | 사건 하나의 3D 공간은 방 여러 개로 이루어진다. 현장에서 강제로 나가야 하는 상황은 없다 |
| 국가 지도 | 시·도 단위. 한국과 일본부터 만든다 |
| 주인공 | 기자. 플레이는 탐정처럼 조사한다 |
| 캠페인 | 이 루프와 별도로 캠페인을 둔다. 지금의 프롤로그와 제1장을 없애고 수능 AI 부정행위 사건으로 바꾼다([캠페인 현장 3D 설계](campaign-3d-design.md)) |

## 경험 목표와 필러 [제안]

> 세상이 '원래 그랬다'고 믿는 것 가운데 무엇이 고쳐졌는지 나만 알아챌 수 있다. 그리고 나도 고칠 수 있다.

| 필러 | 뜻 | 판정 질문 |
|---|---|---|
| 1. 문장이 세계다 | 핵심 동작은 모두 문장을 다룬다: 찾기, 판본 비교, 원문 추적, 찍기, 되돌리기 | 이 기능은 문장을 통해 작동하는가 |
| 2. 찾아낸 것은 내 것이다 | 단서는 주사위가 아니라 관찰과 추론으로 얻는다. 규칙은 공개되고 배울 수 있다 | 플레이어가 "내가 알아냈다"고 말할 수 있는가 |
| 3. 한 문장의 값 | 도장은 언제나 더 빠른 길이고, 언제나 사람의 값(기억, 신뢰)을 치른다 | 도장이 유혹적인가, 대가가 얼굴 있는 사람에게 보이는가 |
| 4. 세계는 기다리지 않는다 | 다른 도장 주인이 세계를 고쳐 쓰고, 고르지 않은 사건도 흔적을 남긴다 | 결과가 지도로 돌아가는가 |

부딪힐 때의 우선순위는 2 > 3 > 1 > 4입니다. 설계 원칙 「숫자는 규칙이, 말은 LLM이」는 「**진실은 규칙이, 목소리는 LLM이**」로 바꿉니다.

하지 않는 것: 경영 수치, 빈 종이에 긴 글 쓰기, 확률로 얻는 단서, 전투와 액션.

## 화면별 역할 [제안]

| 화면 | 할 수 있는 것 |
|---|---|
| 세계지도 | 나라별 사건 수와 이상 징후(의심), 상대 세력의 흔적, 세계 소식. 나라 선택 |
| 국가 지도 | 시·도와 도시, 사건 핀, 사건 개요, 이동 시간, 협력자 위치. 사건 선택과 이동 |
| 이동 | 짧은 전환 연출. 게임 속 시간이 흐른다 |
| 현장 (3D 1인칭) | 돌아다니기, 살펴보기, 증거 집기와 3D 열람, NPC 대화, 방 사이 이동 |
| 수첩·증거판 (덮개) | 증거 잇기, 추리, 대응(환원, 폭로 기사, 도장). 펼치면 시계가 멈춘다 |

**시간**: 이동·살펴보기·대화 한 번에 게임 속 시간이 흐르고, 걷기에는 거의 들지 않습니다. 현장에서 쫓겨나지는 않지만 그동안 다른 사건은 국면을 따라 흘러갑니다.

## 현장의 추리 [제안]

| 동작 | 내용 |
|---|---|
| 살펴보기 | 다가가면 표시가 뜨는 물건: 서류의 날짜, 비어 있는 자리, 손글씨 |
| 집어 들기 | 결정적 증거는 3D로 돌려 보고 뒤집는다(인영, 날짜 도장, 뒷면 메모) |
| 대화 | 자유 질문(LLM). 수첩의 증거를 내밀어 모순을 짚는다 |
| 판본 비교 | 같은 문장의 여러 판본(신문, 자막, 공문)을 모아 원문을 찾는다 |
| 도장 | 막힌 문을 열거나 입을 열게 하는 지름길. 찍힌 NPC는 나와의 기억을 잃는다 |

- 결정적 단서는 언제나 **두 경로**(사람과 물건)로 얻을 수 있게 규칙 엔진이 보장합니다. LLM 대화가 엇나가도 진행이 막히지 않습니다.
- 추리는 무엇을(문장), 언제(찍힌 날), 누가(찍은 자), 왜(동기, 선택)를 맞히는 일입니다. 플레이어가 배우는 **도장의 법칙**은 아래와 같습니다. 옛 제1장의 증거에 맞춰 만든 것이라, 새 캠페인에서 어느 장이 무엇을 가르칠지는 다시 정합니다. 새 프롤로그·제1장에서는 플레이어가 직접 찍을 때 ④를 배웁니다.

| 법칙 | 내용 |
|---|---|
| ① 새것은 날짜를 속이지 못한다 | 도장이 만든 기록은 모두 찍힌 날 이후의 날짜를 단다 |
| ② 옛것은 지우지 못한다 | 이미 있던 물건(손글씨, 실물, 인영)은 바뀌지 않는다 |
| ③ 출처를 물으면 말문이 막힌다 | 모두 알지만 언제 알게 됐는지 말하지 못한다 |
| ④ 찍은 자만 기억한다 | 찍기 전의 세계는 도장 주인만 기억한다 |
| ⑤ 원문은 어딘가 실렸다 | 도장은 공개된 글에만 먹으므로, 토씨까지 같은 원문이 실린 지면이 있다 |

## 사건과 3D 공간 만들기 [제안]

- **장소 원형 키트**: 관공서, 기록실, 방송국, 병원, 공장, 인쇄소, 골목, 항구 창고 등 10~15종을 모듈로 만듭니다. 사건이 생기면 규칙 엔진이 원형을 고르고 방 배치, 소품, 단서 자리를 정합니다. 캠페인 무대만 전용 공간을 씁니다.
- **절차 생성 사건의 문법**: 문장 유형 × 흔적 유형(법칙 두셋) × 찍은 자의 위치(작성자 / 편집자 / 승인자) × 함정 × 도덕적 비틀기. 정답과 단서의 연결은 규칙 엔진이 정하고, LLM은 이름·대사·문서의 문장을 입힙니다.
- **NPC는 종이 인형**: 기존 초상을 3D 공간에 판지처럼 세웁니다(빌보드). 다가가면 대화 덮개가 열립니다.
- **화풍**: 외곽선, 단순한 명암, 종이 질감의 후처리로 지금의 펜·수채 삽화에 맞춥니다.
- **기술**: 브라우저의 three.js. 세계 시뮬레이션·LLM 중계·도장 엔진을 그대로 이어 쓰고, d3처럼 `/vendor/`로 내보냅니다. 조작은 WASD와 마우스 시점, 그리고 클릭 이동.
- **국가 지도 데이터**: 지금은 나라 경계뿐입니다. Natural Earth의 행정구역(시·도) 경계와 도시 점을 더합니다.

## 성장 [제안]

경영 대신 다음이 자랍니다: 도장 각인(사건 해결 보상), 감식 능력(새 법칙과 판본 비교 같은 도구), 협력자(도운 사람이 그 지역의 연줄이 됨), 도장 주인 파일(상대의 버릇), 신뢰도(취재원이 입을 여는 정도).

## 첫 수직 단면 [제안]

캠페인 현장의 공간·단서·수첩·증거판 설계는 [캠페인 현장 3D 설계](campaign-3d-design.md)에 있습니다. 절차 생성 사건의 3D 현장은 뒤로 미룹니다 **[결정]**.

세계 → 대한민국 → 서울 → 양천구 사건까지의 지도 흐름, 3D 공간 「목원고」(12시험실, 복도, 행정실, 시설관리실), 종이 인형 NPC 둘(배수정, 오기철), 단서 다섯(석고 가루, 사다리 자국, 깜빡이는 구멍, 점검표, 출입 기록), 3D 열람 하나(천장 속 장치), 추리 하나(「그날 밤」). 조작감·화풍·대화 덮개·시간 규칙을 한 번에 확인합니다.
